# library-frontend

Frontend for a Library Management System.

Languages
- JavaScript
- CSS
- HTML

Getting started

- Install dependencies:

```bash
npm install
```

- Run locally:

```bash
npm start
```

- Build for production:

```bash
npm run build
```
